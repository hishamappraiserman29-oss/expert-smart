## المحور الأول — البيانات وجودتها

- [ ] **D-01** قاموس البيانات مُطبَّق: كل السجلات المُستوردة تُحقَّق بحقول `data_contract.json` (النوع/الوحدة/الإلزامي).
- [ ] **D-02** قاموس ربط الأعمدة مُطبَّق: المصادر الثلاثة (CSV/XLSX/DB) تُقابَل بـ `column_mapping.json` بلا أخطاء نوع.
- [ ] **D-03** قواعد الجودة الـ 16 مُطبَّقة: كل QR-001→QR-016 يُنتج نتيجة (reject/flag/warn) موثَّقة في سجل الجودة.
- [ ] **D-04** سياسة القيم المفقودة مُطبَّقة: السعر والموقع غير مُعوَّضَين إحصائياً في أي سجل.
- [ ] **D-05** Isolation Forest وZ-score منتجَان للعلم فقط: لا سجل حُذف آلياً بسببهما — التحقّق من سجل التدقيق.
- [ ] **D-06** التقسيم الزمني مُنفَّذ: بيانات التحقّق من فترة **لاحقة** لبيانات التدريب بلا تداخل.
- [ ] **D-07** التقسيم الجغرافي مُنفَّذ: مدينة/حي واحد على الأقل مُستبعَد من التدريب واستُخدم للتحقّق المستقل.
- [ ] **D-08** لا تسرّب بين التدريب والاختبار: `leakage_check=true` في سجل التحقّق وطريقة الفحص موثَّقة.

- [ ] **M-01** COD محسوب ومُقيَّم بالعتبة المُهيَّأة (لا hardcoded 15%) حسب `standard_version.schema.json`.
- [ ] **M-02** PRD محسوب ومُقيَّم بالنطاق المُهيَّأ.

- [ ] **M-07** البذرة العشوائية مُوثَّقة في `audit_trail.schema.json` لضمان إعادة الإنتاج.
- [ ] **M-08** Hash البيانات + Hash النموذج + Code Commit مُسجَّلة في سجل التدقيق.
